# Mosaic Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename the framework to Mosaic, fix all 15 audit findings, and make widget content runtime-data-bound, with a runnable Dart test suite.

**Architecture:** DSL (Dart) → IR (JSON) → native codegen (Kotlin/Swift). Generated native code becomes a thin runtime renderer that reads a shared data store each refresh and resolves `MBind` references. Layout stays codegen'd; content is dynamic.

**Tech Stack:** Dart 3.12, Flutter 3.44, `package:test`, `json_serializable`/`build_runner`, `args`, `yaml`, `path`. Native targets Android RemoteViews/Kotlin and iOS WidgetKit/Swift (generated as strings; verified by golden tests, compiled by the user locally).

**Spec:** `docs/superpowers/specs/2026-05-31-mosaic-production-dynamic-design.md`

**Working dir:** `/Users/omarabed/Documents/projects/hw_flutter`. Pure-Dart packages live under `platform/{core,cli,android,ios}`; the Flutter package under `platform/flutter`. Run Dart tests with `dart test` inside each package dir. `dart` and `flutter` resolve via fvm.

import 'dart:io';
import 'package:hw_android/hw_android.dart';
import 'package:hw_core/hw_core.dart';
import 'package:path/path.dart' as p;

class GenResult {
  final Directory root;
  GenResult(this.root);

  String file(String relative) =>
      File(p.join(root.path, relative)).readAsStringSync();

  bool exists(String relative) => File(p.join(root.path, relative)).existsSync();
}

/// Runs AndroidGenerator against a throwaway project dir.
Future<GenResult> runAndroid(
  List<IRDefinition> defs, {
  HWConfig? config,
}) async {
  final dir = Directory.systemTemp.createTempSync('mosaic_android_');
  // Minimal android project skeleton the generator writes into.
  Directory(p.join(dir.path, 'android', 'app', 'src', 'main', 'res'))
      .createSync(recursive: true);
  final cfg = config ??
      HWConfig.fromJson({
        'app': {
          'bundle_id': 'com.acme.app',
          'android_package': 'com.acme.app',
          'ios_app_group': 'group.com.acme.app.widgets',
        },
        'widgets': [
          {
            'name': defs.first.name,
            'entry': 'lib/w.dart',
            'android': {'min_sdk': 21, 'sizes': ['medium']},
            'ios': {'families': ['systemMedium']},
          }
        ],
      });
  final gen = AndroidGenerator(config: cfg, definitions: defs);
  await gen.generate(dir.path);
  return GenResult(dir);
}
```

/// Escapes a string for safe interpolation into an XML attribute/text value.
String xmlEscape(String s) => s
    .replaceAll('&', '&amp;')
    .replaceAll('<', '&lt;')
    .replaceAll('>', '&gt;')
    .replaceAll('"', '&quot;')
    .replaceAll("'", '&apos;');

/// Escapes a string for a Kotlin double-quoted string literal.
String kotlinEscape(String s) => s
    .replaceAll('\\', r'\\')
    .replaceAll('"', r'\"')
    .replaceAll(r'$', r'\$')
    .replaceAll('\n', r'\n')
    .replaceAll('\r', r'\r')
    .replaceAll('\t', r'\t');

/// Escapes a string for a Swift double-quoted string literal.
String swiftEscape(String s) => s
    .replaceAll('\\', r'\\')
    .replaceAll('"', r'\"')
    .replaceAll('\n', r'\n')
    .replaceAll('\r', r'\r')
    .replaceAll('\t', r'\t');

/// Converts an arbitrary string into a valid identifier
/// (`[A-Za-z_][A-Za-z0-9_]*`). Non-identifier chars are dropped;
/// a leading digit gets a `_` prefix; empty input becomes `_`.
String sanitizeIdentifier(String s) {
  final cleaned = s.replaceAll(RegExp(r'[^A-Za-z0-9_]'), '');
  if (cleaned.isEmpty) return '_';
  return RegExp(r'^[0-9]').hasMatch(cleaned) ? '_$cleaned' : cleaned;
}
```

Note ordering: backslash is replaced first so later inserted backslashes are not double-escaped.
